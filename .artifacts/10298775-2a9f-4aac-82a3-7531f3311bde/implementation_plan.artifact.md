# Удаление пункта "Системный промпт" из настроек

Задача состоит в том, чтобы убрать переключатель "Использовать системный промпт" из диалога настроек приложения. Этот параметр дублирует функциональность переключения режимов "Чат/Календарь" в верхней панели и является избыточным в меню настроек.

## Предложенные изменения

### UI Компоненты

#### [MODIFY] [ChatScreen.kt](file:///C:/Users/007/AndroidStudioProjects/AIAssistent1/app/src/main/java/com/example/aiassistent1/presentation/ui/ChatScreen.kt)
1. Изменение сигнатуры `ModelSettingsDialog`: удаление параметра `systemPromptEnabled` и соответствующего поля в `onSave`.
2. Удаление состояния `systemPrompt` и `Row` с переключателем "Использовать системный промпт" из реализации `ModelSettingsDialog`.
3. Обновление вызова `ModelSettingsDialog` в `ChatScreen`, чтобы не передавать и не обрабатывать этот параметр.
