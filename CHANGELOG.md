# Журнал изменений (Changelog)

## [1.0.1] - 2026-08-17

### Добавлено
- **AI Calendar Agent**: Реализована поддержка системного промпта, который заставляет LLM возвращать ответы в формате JSON для управления календарем.
- **Интенты**: Поддержка интентов `calendar_search` (поиск событий) и `calendar_add` (добавление событий).
- **Парсинг**: `AssistantResponseParser` для автоматической обработки JSON-ответов от ассистента.
- **Поиск в календаре**: В `AndroidCalendarProvider` добавлен метод `searchEvents` для поиска по ключевым словам и диапазону дат.
- **Системный контекст**: `SystemPromptProvider` динамически передает текущую дату и время в модель для корректной работы с относительными датами ("завтра", "в среду").

### Изменено
- **Интерфейс**: Время отображения Snackbar-уведомлений увеличено с 2 до 5 секунд в `ChatScreen` для удобства чтения.
- **Инъекция зависимостей**: `AppModule` и `MainActivity` обновлены для поддержки новых UseCase и парсеров.
- **UseCase**: `SendMessageUseCase` теперь автоматически внедряет системную инструкцию в контекст диалога.

### Исправлено
- Исправлены критические ошибки компиляции, связанные с неразрешенными ссылками на тему `AIAssistent1Theme` и расширение `voiceDraftStore`.
- Упорядочены импорты в ключевых компонентах проекта.
