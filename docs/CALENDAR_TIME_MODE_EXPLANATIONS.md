# Пояснения режимов времени и расположение пересчёта

В редакторе черновика календарного чата существующий блок пересчёта перенесён под поле «Время». Формулы, условия показа, обработка ошибок и отдельная строка окончания при скрытом пересчёте сохранены.

В ручном редакторе календаря тот же существующий блок перенесён из-под «Ценность события» сразу под «Начало (ЧЧ:ММ)». При разных поясах он показывает пересчёт начала и указанного окончания. При совпадающих поясах и в режиме «Всегда по местному времени» блок пересчёта скрыт. Условия вывода ошибок времени сохранены отдельно от видимости блока. Аргументы компонента и расчёт окончания перенесены без изменений.

Общий компонент обоих редакторов показывает описание только выбранного режима времени. Названия обоих режимов остаются доступны для переключения. Для повторения выводится пояснение выбранного варианта. При каждом открытии блок «Режим времени» по-прежнему свёрнут.

## Смысл настроек, проверенный по реализации

Настройка ввода определяет, что означают введённые часы. Режим события определяет его поведение при смене пояса календаря. Это независимые решения.

- «По времени телефона»: новый запрос или редактор получает текущий пояс Android. Приложение обновляет его при системном сообщении о смене пояса, возвращении в приложение и перед получением контекста запроса.
- «Домашний пояс»: выбранный пояс используется для ввода и сохраняется при поездках. Его изменение не переносит уже сохранённые события. В подсказке явно указано, что без выбранного домашнего пояса используется пояс телефона.
- Общий пояс календаря определяет отображение, поиск и календарные диапазоны. По умолчанию он следует за телефоном; ручной выбор сохраняет выбранный пояс.
- Фиксированное событие хранит конкретный момент. Например, 20 октября 2026 года, 09:00 в Самаре — это 08:00 в Москве. Переключение отображения не меняет сохранённый UTC-момент. Фиксированная серия хранит исходный пояс своего расписания.
- В режиме «Всегда по местному времени» исходными являются дата и часы без привязки к поясу. При просмотре в Самаре и Москве остаётся 09:00, а рассчитанный для этого пояса момент различается.
- Открытый или восстановленный черновик сохраняет захваченный пояс ввода. Смена общей настройки не переосмысливает ранее введённые часы; для применения новой настройки предусмотрено явное действие.

Приложение читает часовой пояс Android. Географическое перемещение без изменения системного пояса само по себе не переключает эти настройки.

Утверждение об отображении всех существующих и будущих событий относится к общему поясу календаря. Домашний пояс используется для ввода. У местного режима часы сохраняются; это отдельно объясняется при его выборе.

После дополнительного согласования описание «Фиксированный момент» уточнено в общем компоненте обоих редакторов: ввод происходит по текущему поясу телефона или выбранному домашнему поясу; по умолчанию используется пояс телефона. Остальные предложения описания, текст местного режима и подсказка рядом с выбором домашнего пояса сохранены.
