# Часовые пояса при создании события

В «Настройки → Часовые пояса» выбирается один режим для новых событий календаря и календарного чата. Зелёная галочка отмечает действующий выбор. При открытии раздела все описания свёрнуты. Нажатие выбирает режим и раскрывает его пример, повторное нажатие сворачивает описание. При первом выборе домашнего пояса открывается список с поиском по городу. При отмене поиска сохраняется предыдущий режим.

| Режим | Ввод времени и результат |
|---|---|
| Фиксированный момент | Для ввода используется пояс календаря при создании. Звонок на 09:00 по Самаре отображается в московском поясе в 08:00. |
| Всегда по местному времени | Сохраняются часы и дата расписания. Прогулка остаётся в 09:00 при смене пояса просмотра. При закреплённом вручную поясе календаря эти 09:00 относятся к нему. |
| По времени телефона | Для новой записи используется текущий системный пояс Android. Если телефон в Москве, введённые 15:00 означают 15:00 по Москве. |
| Домашний пояс | Для ввода используется сохранённый домашний пояс. Планёрка на 09:00 по Самаре в московском календаре отображается в 08:00. |

На новой установке выбран режим «По времени телефона». При первом чтении старых настроек выбранный ранее домашний пояс активирует режим «Домашний пояс». Приложение хранит имя режима и домашний пояс вместе в существующем DataStore. Выбор другого режима сохраняет домашний город для следующей поездки.

При открытии ручного редактора и в начале запроса календарного чата приложение фиксирует источник времени и правило расписания. Черновик чата сохраняет их в существующих полях. Поэтому выбор режима для следующей записи сохраняет первоначальный смысл времени в открытых и восстановленных черновиках. Редактор сохранённого события использует правило самого события. Таблица событий и сохранённые моменты встреч не требуют миграции.

Повторения, даты и дни недели выбираются в редакторах. Если требуется подтверждение пояса старого черновика, действия доступны под полем времени. Там же появляется компактный пересчёт при расхождении поясов для фиксированного времени. Для местного расписания длительность между указанными началом и окончанием считается по местным часам, в том числе при переходе на летнее время.

## Проверка

Прошли 883 модульных теста, один тест сравнения настольных ответов модели пропущен. На эмуляторе Android 14 прошли 33 инструментальных теста календаря. Проверки охватывают раскрытие всех четырёх примеров в настройках, выбор и отмену домашнего пояса, открытие редактора до завершения чтения настроек, сохранение выбора для нового черновика, повторения и пересчёт времени. После переключения каждого режима сохранённое событие считано из Room и сверено с исходной записью. Lint завершился с 58 предупреждениями и двумя подсказками, ошибок нет.
