# Начальные размеры контекста и ответа в ручном режиме чата

23 ноября 2026 года.

| Доля ответа | Контекст по умолчанию | Размер ответа по умолчанию |
|---|---:|---:|
| 1/2 | 2048 токенов | 1024 токена |
| 1/4 | 4096 токенов | 1024 токена |

Первый переход в ручной режим использует выбранную долю и вычисляет контекст
как `1024 × делитель`. Новый профиль чата по-прежнему начинает с доли 1/4.
Подписи «По умолчанию» и отметки на обеих шкалах используют тот же расчёт.
Кнопка обновления рядом с «По умолчанию» у контекста возвращает его к этому
значению и пересчитывает размер ответа по выбранной доле. Используется тот же
компонент сброса, что у Temperature.
Это заменяет прежние начальные 1024 токена контекста и 256 токенов ответа.

Предел GGUF ограничивает начальный контекст с округлением по сетке модели;
размер ответа затем пересчитывается по доле. Поэтому для модели с меньшим
пределом фактические значения по умолчанию могут быть меньше таблицы.
Текущая свободная RAM не меняет эти значения: доступность памяти проверяет движок.

Каждая доля запоминает собственные положения шкал для выбранной модели.
При первом выборе действуют значения из таблицы, при возврате восстанавливаются
последние значения для этой доли. Кнопка сброса действует на выбранную долю.
Подробнее о [сохранении и совместимости](CHAT_MANUAL_RATIO_POSITIONS.md).

Единый расчёт начальных значений и отметок исключает расхождение между шкалами
и первым переходом в ручной режим. Алгоритм автоматического подбора не изменён.

Проверки покрывают обе доли, предел модели, нехватку RAM и сохранение старых
ручных размеров. Команда `./gradlew.bat :app:testDebugUnitTest :app:compileDebugAndroidTestKotlin --offline`
завершилась успешно: 871 unit-тест пройден, 1 пропущен, ошибок нет.
UI-тест смены отметок скомпилирован; запуск на устройстве не выполнен.
