# Стандартное редактирование текста

Дата: 2026-10-20.

Во всех полях приложения применяется общий модификатор `standardTextEditing()`:

- В контекстном меню разрешены только стандартные действия Compose: вырезать, копировать,
  вставить и выделить всё. Доступность каждого действия определяет само поле.
- Автозаполнение и дополнительные действия обработки текста исключены из меню.
- Для Android-хоста поля установлен `IMPORTANT_FOR_AUTOFILL_NO_EXCLUDE_DESCENDANTS`,
  а для самого поля — `ContentDataType.None`. Системное автозаполнение отключается
  также в отдельных окнах диалогов.

Охвачены основной ввод чата, имя ассистента, поля редакторов и черновиков календаря,
поиск часовых поясов, параметры повторения, название и поиск конференций.
Модификатор добавлен также к `DatePicker`, чтобы правила распространялись на его
встроенное поле ручного ввода даты.

Общий модификатор сохраняет штатные действия Compose и их обработчики, поэтому
редактирование, ограничения длины, сохранение черновиков и голосовые функции
продолжают использовать существующую логику. Настройки клавиатуры не изменены.
Новые поля ввода и контейнеры библиотечных редакторов должны использовать этот
модификатор, включая поля в новых диалогах.
