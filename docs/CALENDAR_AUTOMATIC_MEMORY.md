# Автоматический режим памяти календаря

Календарь измеряет полный запрос и выбирает контекст с учётом предела модели и доступной памяти. Вход обрабатывается пакетами до 64 токенов. При заполнении контекста движок пробует расширить его, сохраняя размер пакета.

Во вкладке «Календарь» остаются заголовок и описание режима. Сохранённые в прежних версиях ручные значения контекста, доли и лимита ответа, размера пакета и переключателей памяти больше не применяются. Остальные параметры модели, включая температуру и настройки CPU, продолжают читаться из этого профиля.

При переходе из чата календарь может повторно использовать подходящий контекст с пакетом 64. Если чат использовал другой пакет, движок проверяет возможность выделить контекст для календаря. Так фактический размер пакета соответствует указанному в настройках и при нехватке памяти.
