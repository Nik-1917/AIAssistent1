# Анимация переходов между основными экранами

Дата: 19 октября 2026 года.

Порядок страниц слева направо: **календарный чат — календарь — свободный чат**.
В `AIAssistantApp` направление анимации определяется положением исходной и целевой
страницы с учётом режима чата. Раньше календарь всегда появлялся справа, а любой чат
слева, поэтому переходы между календарём и свободным чатом нарушали этот порядок.

| Переход | Появление новой страницы |
| --- | --- |
| Календарный чат → календарь | Справа налево |
| Календарь → свободный чат | Справа налево |
| Свободный чат → календарь | Слева направо |
| Календарь → календарный чат | Слева направо |

Сохранены длительности появления и ухода: 360 и 300 мс, затухание и смещение
уходящей страницы на пятую часть ширины по направлению движения.
Неподвижная подложка контейнера заполняет экран цветом
`MaterialTheme.colorScheme.background`: в тёмной теме она тёмная, в светлой — светлая.
Подложка остаётся видимой за смещаемыми и полупрозрачными страницами.

Изменение ограничено отображением переходов в `AIAssistantApp`. Обработчики
навигации, хранение состояния, история, календарные данные и голосовая логика
не изменены. Ключ содержимого по-прежнему различает `CHAT` и `CALENDAR`: прямое
переключение режима внутри чата сохраняет прежнее поведение без анимации и без
создания двух экземпляров `ChatScreen` с общими обработчиками.
