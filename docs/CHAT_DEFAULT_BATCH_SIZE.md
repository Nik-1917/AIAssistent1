# Размер пакета по умолчанию в профиле «Чат»

24 ноября 2026 года.

Размер пакета в `ModelProfile.CHAT.defaults` изменён со 128 на 64 токена.
Он используется при отсутствии сохранённого значения и при первом переходе
в ручной режим. Подпись «По умолчанию» и отметка на шкале размера пакета
также используют это значение.

Единый параметр профиля сохраняет согласованность начального размера,
подписи и отметки шкалы. Сохранённый пользователем ручной размер пакета
продолжает применяться; для его изменения нужно выбрать 64 на шкале.
В автоматическом режиме фактический пакет по-прежнему подбирается движком.

Обновлены существующие проверки параметров профиля, первого перехода
в ручной режим, передачи пакета движку и подписей в интерфейсе.

Проверка: 82 unit-теста в восьми связанных классах прошли без ошибок и пропусков.
Компиляция приложения и UI-тестов (`:app:compileDebugAndroidTestKotlin`)
завершилась успешно. UI-тесты на устройстве не запускались.
