# Меню моделей в заголовке чата

При нажатии на название ассистента открывается список GGUF из папки моделей приложения. Файлы упорядочены по фактическому размеру: самый крупный сверху. В каждой строке одинаковой ширины показаны имя без `.gguf`, размер файла и корзинка; длинное имя сокращается многоточием. Активная модель выделена цветом и начертанием.

Пункт «Загрузить модель .gguf» расположен после моделей, а при пустом списке становится первым. Он открывает тот же системный выбор файла, что и экран первого запуска. Импорт копирует файл в папку приложения, проверяет расширение, размер файла и ограничение в пять моделей. Если источник сообщает размер заранее, также проверяется свободное место. Ограничение проверяется по файлам на диске внутри последовательной операции, поэтому повторные нажатия не позволяют импортировать шестую модель.

Корзинка удаляет файл из папки приложения только после подтверждения. Если удалена активная модель, приложение сначала останавливает генерацию и выгружает её, затем выбирает самый крупный оставшийся файл. При пустом списке выбор очищается. Исходный файл, из которого выполнялся импорт, не удаляется. Модели хранятся как файлы; в памяти для генерации используется одна выбранная модель.

Это меню позволяет переключаться между сохранёнными моделями и освобождать место без очистки данных приложения.
