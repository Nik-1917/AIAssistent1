# Обновление календаря без сброса выбранной даты

При обновлении календаря жестом вниз сохраняются выбранное число и отображаемый месяц. Например, после выбора 18 февраля 2031 года обновление должно оставить календарь на этой дате.

В `CalendarViewModel.refreshCalendar()` убраны переход на сегодняшний день и запись сегодняшней даты в настройки позиции календаря. Счётчик обновления по-прежнему запускает повторный запрос событий для отображаемого месяца.

Обработка анимации, минимальная длительность индикатора, защита от повторного обновления и сброс фокуса события сохранены. Создание, изменение и удаление событий, выбор часового пояса и навигация календаря не изменялись в рамках этого исправления.

Так обновление загружает актуальные события, сохраняя выбранный пользователем день.

Проверка: выполнена задача `:app:testDebugUnitTest` с фильтром `com.example.aiassistent1.presentation.viewmodel.CalendarViewModelTest`. Все 13 существующих тестов прошли; `git diff --check` для изменённого Kotlin-файла ошибок не выявил. Эти тесты не проверяют жест обновления; проверка жеста и анимации на физическом устройстве не выполнялась.
