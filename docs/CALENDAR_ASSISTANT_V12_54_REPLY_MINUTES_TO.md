# V12.54: формы «без … минут» только в reply

Основа — V12.53. V12.54 меняет оформление известного времени в ответе.
JSON-контракт остаётся прежним: шесть намерений, без `note_add`.

## Правило ответа

**Правило действует исключительно внутри `reply`, в выражениях времени
начала или окончания события.**

| Точное время | Форма в reply |
| --- | --- |
| 14:15 | в четверть третьего |
| 14:30 | в половине третьего / в полтретьего |
| 14:35 | без двадцати пяти минут три |
| 14:40 | без двадцати минут три |
| 14:45 | без четверти три |
| 14:50 | без десяти минут три |
| 14:55 | без пяти минут три |

После «без … минут» называют следующий час количественным числительным:
«час», «два», «три», …, «двенадцать». Уточнения «утра», «дня», «вечера»,
«ночи» при озвучивании часов опускаются, как в V12.53.
Перед «без» не добавляют «в», «с» или «до». Для интервала подходят отдельные
части: «начало без двадцати минут три, окончание без пяти минут три».

Другие минуты сохраняют точное значение: `14:34` и `14:36` не становятся
«без двадцати пяти минут три». Существующие четверти, половины и «без
четверти» сохраняются. Ответ без указанного времени не дополняют выдуманным
временем.

## Границы суток и область действия

| Точный момент | Произносимое время | Сохранённое время |
| --- | --- | --- |
| 2027-09-01T00:35 | без двадцати пяти минут час | 2027-09-01T00:35 |
| 2027-09-01T11:40 | без двадцати минут двенадцать | 2027-09-01T11:40 |
| 2027-09-01T12:50 | без десяти минут час | 2027-09-01T12:50 |
| 2027-12-31T23:55 | без пяти минут двенадцать | 2027-12-31T23:55 |

Упоминание следующего часа не переносит дату или начало события. Дату
окончания по-прежнему определяет исходная длительность. Часть суток берут
из входного запроса при вычислении параметров; сокращённый `reply` не
используют для обратного вычисления 24-часового времени.

Правило не изменяет `intent`, `params`, вложенные `target` и `changes`,
входные сообщения, system-контекст, сохранённые даты и время, названия,
поисковые запросы, длительности и значения. Точная копия названия внутри
`reply` также сохраняется. «На сорок минут», «через пятьдесят минут»,
«через три дня» и «Сверка плана следующего дня» не являются заменяемыми
выражениями времени на часах.

## Ручные материалы и состав набора

[Реестр ручных ответов](calendar_assistant_v12_54_reply_edits_manual.json)
содержит 180 полностью написанных строк `reply`, привязанных к существующим
`case_id`. Сборщик проверяет текст до и после выражения времени, его
соответствие `starts_at` и неизменность остальных полей. Он копирует полную
строку из реестра; шаблоны предложений и автоматическая замена слов не
используются для составления ответов.

| Выборка | Всего записей | Изменено reply |
| --- | ---: | ---: |
| train | 2401 | 144 |
| validation | 720 | 36 |
| holdout | 36 | 0 |
| calendar_holdout_v12_2 | 8 | 0 |
| regression_holdout | 63 | 0 |
| Всего | 3228 | 180 |

В train каждой из четырёх новых форм соответствуют 36 ответов. Основная
сетка V12.53 покрывает все 24 часа; сохранены дополнительные примеры V12.52
с порядковым обозначением следующего часа. В прежней validation-сетке новые
формы затрагивают только минуту `55`: 36 ответов. Состав выборок и порядок
записей сохранены. Эта подготовка не является проверкой качества модели.

Выходные файлы находятся в [calendar_sft_v12_54](calendar_sft_v12_54).
Исходные наборы и ручные материалы V12.53 сохранены. Все неизменяемые строки
и три holdout-файла копируются побайтно.

В приложении те же формы добавлены в `CalendarReplyTimeFormatter` для
подтверждения начала и окончания события. Извлечение параметров, CLI,
парсер, Room и расчёт длительности этой правкой не меняются.
