# Сброс отдельных параметров модели

В блоках Temperature, Top P, Top K и Repeat Penalty рядом со значением
«По умолчанию» добавлена круглая кнопка со значком обновления.
Область нажатия составляет 48 dp, значок с фоном занимает 30 dp.
Для экранного диктора у каждой кнопки есть название параметра и действия.

Нажатие передаёт значение из текущего профиля в существующий обработчик
ползунка. Восстанавливается один параметр. Temperature календаря возвращается
к 0.07, Temperature чата — к 0.70. Остальные исходные значения берутся
из `ModelProfile.defaults`.

Изменение сохраняется обычным механизмом редактора, включая закрытие окна,
сворачивание раздела и переключение профиля. Это позволяет быстро вернуть
параметр к исходному значению после экспериментов.

Добавлены UI-сценарии для обоих профилей с последовательным сбросом каждого
параметра, проверкой остальных значений и повторным открытием окна.

Unit-тесты приложения прошли. UI-сценарии скомпилированы, запуск на устройстве
и визуальная проверка кнопок пока не выполнены.
