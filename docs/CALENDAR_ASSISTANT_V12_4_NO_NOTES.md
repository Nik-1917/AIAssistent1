# V12.4: календарный набор без заметок

Дата подготовки: 2026-09-09.

V12.4 вручную получен из `calendar_sft_v12_3` удалением всех записей с intent
`note_add`. Остальные строки сохранены в исходном порядке и без редактирования;
новые примеры не генерировались.

В обучающий набор входят только intents `chat`, `calendar_add`,
`calendar_search`, `calendar_update`, `calendar_delete` и `calendar_sum`.
Проверены количества: 1950 train, 581 validation, 36 новый holdout,
8 календарный holdout и 63 regression holdout. В новом наборе нет строк
с `note_add`.

Android-парсер теперь отклоняет неизвестные intents, включая удалённый
`note_add`, и больше не создаёт отдельный параметр для текста заметки.
Календарные DTO, извлечение дат и времени, обновление и удаление событий
остались без изменений.

Существующий файл `calendar-assistant-v12.3-Q4_K_M.gguf` не переписывался:
он был обучен на V12.3 и требует отдельного переобучения на V12.4, если нужен
вес, обученный без записей заметок.
