# V12.2: проверка подсказки о количестве дней в месяце

Дата проверки: 2026-09-08. Процесс завершён с кодом 0.

## Вывод

Добавление строки `Дней в текущем месяце: N` без дообучения не устранило ошибки конца месяца и ухудшило результат на проверенном наборе. Рекомендация по этому эксперименту: сохранить прежний контекст V12.2. В приложение подсказка не добавлялась.

Из 71 случая два ранее ошибочных стали проходить, но девять ранее проходивших перестали. Число строгих несовпадений выросло с 30 до 37. Это результат фиксированного диагностического набора, а не оценка доли ошибок во всех реальных запросах.

## Условия сравнения

- Использованы только существующие 8 календарных holdout-вопросов V12.2 и 63 прежних regression_holdout-вопроса. Вопросы и эталоны не редактировались.
- Оба варианта запущены заново: 142 оцениваемых ответа. Все 71 контрольный ответ без подсказки совпали с сохранёнными ответами предыдущего прогона V12.2.
- Единственное различие входа: в конец системного сообщения второго варианта добавлена новая строка `Дней в текущем месяце: N`. Число вычислено через `calendar.monthrange` из даты конкретного теста, не из даты запуска проверки.
- База: локальная Qwen3-4B-Instruct-2507, revision `cdbee75f17c01a7cc42f958dc650907174af0554`, с неизменным адаптером V12.2.
- Инференс: NF4, FP16, GTX 1080 Ti, greedy decoding, batch 4, максимум 128 новых токенов. Состав и порядок вопросов в пакетах одинаковы; порядок двух вариантов чередовался между пакетами.
- Два коротких прогрева с лимитом 4 токена исключены из замеров. Эталонный финальный assistant-ответ не передавался модели.
- Правила оценки прежние: допустимый контракт V12.1 и точные intent/params. Для создания reply должен содержать только фактическое название либо прежнюю фразу об отсутствующем названии. Для остальных intent точное совпадение формулировки reply не требуется.

Все ответы являются выводом модели в тестовом прогоне, а не исполненными командами календаря. События не создавались, не изменялись и не удалялись.

## Время и размер контекста

- Суммарное измеренное время 18 пакетов без подсказки: **395,38 с**.
- С подсказкой: **398,61 с**, на **3,23 с / 0,82%** больше в этом прогоне.
- Подсказка добавила ровно **12 входных токенов** на вопрос: среднее 64,61 -> 76,61.
- Число токенов декодированного текста ответов также различалось: 3969 -> 4007.

Это один пакетный прогон каждого варианта на ПК, с синхронизацией CUDA и исключённым прогревом. Замер включает токенизацию, генерацию и декодирование, но не загрузку модели. Он не доказывает устойчивое замедление на 0,82% и не является замером задержки одного ответа на Android.
