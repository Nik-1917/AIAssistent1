# Закрытие уведомлений чата

Изменение от 7 октября 2026 года, согласовано: «Закрыть» и разная длительность ошибок и информации.

В `ChatScreen` уведомление об ошибке (Snackbar) получило текстовую кнопку «Закрыть» и `SnackbarDuration.Indefinite`. Автоматического таймера для ошибок больше нет: длинное сообщение об отказе загрузки модели остаётся доступным для чтения, пока пользователь его не закроет. После нажатия вызывается существующий `clearError()`. При смене или очистке ошибки состоянием приложения прежнее уведомление убирается через существующий `LaunchedEffect(uiState.error)`.

Информационная карточка (`uiState.snackbarMessage`: копирование, сохранение, изменение или удаление события) получила отдельную текстовую кнопку «Закрыть», вызывающую существующий `clearSnackbar()`. Прежний таймер 5 секунд сохранён. Кнопка позволяет убрать сообщение сразу после прочтения. Классификация использует существующие поля состояния, а не поиск слов в русском тексте ошибки.

Закрытие по касанию вне границ не добавлено, согласно выбору пользователя. Кнопки относятся к состоянию уведомления; обработчики остановки генерации, микрофона, речи, контекстных диалогов и календарных данных не менялись.

Проверка: `:app:assembleDebug`, `:app:assembleDebugAndroidTest` и `:app:lintDebug` завершились успешно. Lint: 0 ошибок, 49 предупреждений, 2 подсказки. `git diff --check` без ошибок. Новые тесты для этой локальной UI-правки не добавлялись. Основной APK обновлён на подключённом Xiaomi 2201116SC командой установки с сохранением данных. SHA-256 установленного APK совпал с собранным: `fc8aea550e1454e5aaba3f75c8b7b93b4edf7d14904a49c0c7f5c11238c89d1b`. SHA-256 выбранных файлов настроек и календарных черновиков совпал до и после тестов и обновления. Нажатия новых кнопок на физическом телефоне пока не проверены.

Справка: [Snackbar в Jetpack Compose](https://developer.android.com/develop/ui/compose/components/snackbar) поддерживает кнопку действия и отдельное управление длительностью показа.
