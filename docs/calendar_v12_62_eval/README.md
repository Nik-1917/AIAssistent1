# Проверка генерации V12.62

Независимые запросы записаны вручную после фиксации обучающего набора,
до просмотра ответов V12.62. Они не входят в обучение и не используются
для изменения весов. Файл `clock_cases.txt` проверяет все 60 значений минут
на одном часовом интервале и отдельно остальные 23 часа. M15 — точный
запрос пользователя с ошибкой :15 → :30.

Для каждого запроса отдельно оцениваются JSON/контракт, intent, точные
params, время в params и буквальная нормативная фраза часов внутри reply
(регистр, пробелы и ё/е нормализуются). Наличие фразы не заменяет проверку
отсутствия другого, противоречащего времени. Заголовки оцениваются отдельно
с учётом регистра; произвольные синонимы автоматически не засчитываются.

Дополнительно предусмотрены длительности, разговорный ввод, интервал
через полночь и повтор исходного запроса с фактическим системным промптом
приложения. Результаты с обучающим форматом контекста и форматом Android
фиксируются раздельно. Проверка настольного GGUF не является проверкой
работы Android-приложения на физическом телефоне.
