# Счётчик, остановка на лимите и шумоподавление аудиочерновика

Дата: 20.10.2026.

Последующее изменение хранения и отдельные текстовые черновики: [VOICE_DRAFT_SAVED_TEXTS_AND_RECOVERY_2026-10-20.md](VOICE_DRAFT_SAVED_TEXTS_AND_RECOVERY_2026-10-20.md).

## Поведение

- Под текстом карточки показан счётчик `1250 / 3000` в стиле счётчика основного поля ввода. Он обновляется с каждой поступившей распознанной фразой и учитывает пробелы. Распознавание остаётся по речевым фрагментам; частичный текст внутри ещё не распознанной фразы не отображается.
- Лимит и счётчик используют одно значение `VoiceDraftState.MAX_CHARACTERS = 3000`. Условие заполнения — `characterCount >= MAX_CHARACTERS`.
- При достижении лимита сохраняются первые 3000 символов, микрофон останавливается, карточка автоматически сворачивается. Превышающая часть последней фразы не добавляется.
- Полный черновик открывается для просмотра, отправки и удаления. Запись не запускается и разрешение на микрофон для просмотра не запрашивается. Счётчик заполненного черновика выделяется цветом ошибки темы.
- Если осталось место только для разделительного пробела между фразами, он заполняет последний символ: запись также останавливается, а не остаётся включённой с недостижимым остатком.
- Над строкой «Запись» находится переключатель «Шумоподавление: вкл/выкл». Переключение применяется к текущему сеансу без перезапуска микрофона и распознавания.
- Новый черновик использует прежнее значение по умолчанию: шумоподавление включено. Выбор сохраняется при сворачивании и открытии этого черновика в текущем `ChatViewModel`, включая автоматическое сворачивание. В хранилище по-прежнему сохраняется только текст; после отправки, удаления или пересоздания `ChatViewModel` настройка возвращается к включённому состоянию.

## Реализация и причина

`VoiceDraftState` определяет длину, заполненность, открытие и добавление фраз. `ChatViewModel` применяет тот же результат к интерфейсу и остановке сеанса. При заполнении сначала останавливается микрофон с инвалидированием сеанса, затем итоговый текст сохраняется через `VoiceDraftPersistence`; после подтверждения записи обновляется текст и сворачивается карточка. Запоздавшие фразы старого сеанса не дописываются в закрытый черновик.

Для шумоподавления добавлены параметр непрерывной записи и управление по идентификатору сеанса. Изменение от старого черновика не применяется к следующему микрофону. Если переключатель изменён во время запуска микрофона, последнее выбранное значение применяется к открывшемуся процессору.

`AudioProcessingManager.Session` сериализует обработку кадров, переключение шума и закрытие. JNI включает или обходит только WebRTC NS. AEC, его накопленное состояние, опорный звук, защита от самоподхвата озвучивания и готовность эхоподавления сохраняются. При повторном включении заново инициализируется только NS. Для системного Android fallback переключается отдельный `NoiseSuppressor`; ошибка переключения возвращается в интерфейс.

Обычный микрофон и запись профиля/ключевого слова запускаются с прежним включённым шумоподавлением. Конференции используют прежние аргументы с прежними значениями по умолчанию. Основной текстовый ввод, озвучивание и операции с календарными данными этим изменением не перерабатывались.
