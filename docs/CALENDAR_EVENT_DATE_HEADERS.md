# Дата в заголовках создания события — 17 октября 2026

Заголовок «Новое событие» в ручном календаре и заголовок «Черновик события»
в редакторе черновика из чата календаря заменены датой события.

Настройка «Краткие даты и время» управляет форматом этих заголовков:

- включена: `Дата: 17 октября суббота`;
- выключена: `Дата: 17 октября 2026 суббота`.

В этих заголовках месяц присутствует всегда, год — только в полном режиме.
День недели вычисляется по дате события. Общий метод `eventEditorDate()`
в `UserDateTimeFormatter` обеспечивает одинаковый формат в обоих редакторах.

При ручном создании повторная строка даты под заголовком убрана.
В черновике заголовок следует за текущим содержимым поля даты, включая
несохранённые правки: пустое поле показывает `Дата: Не заполнено`,
неполная или некорректная дата — `Дата: Проверьте дату`.

Дата в заголовке помогает сразу проверить день создаваемого события.
Изменение касается отображения; сохранение и проверка обязательных полей
работают по прежним правилам. Редактируемая дата черновика остаётся в формате
`ГГГГ-ММ-ДД`, в командах и хранилище используются исходные значения.
