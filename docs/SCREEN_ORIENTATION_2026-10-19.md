# Настройки экрана: фиксация ориентации

## Поведение

В настройках добавлен раскрывающийся раздел **«Экран»**.

- **«Фиксация ориентации»** включает или отключает ограничение ориентации приложения.
- Один переключатель **«Вертикально / горизонтально»** выбирает режим: выключен — вертикально, включён — горизонтально. Текущий выбор подписан под названием.
- При выключенной фиксации выбор виден, но недоступен. Последний выбранный режим сохраняется для следующего включения.
- По умолчанию фиксация выключена, выбран вертикальный режим.
- После отключения фиксации приложение возвращает управление поворотом системе. Системная блокировка автоповорота продолжает учитываться.

## Реализация и причина выбора

`ScreenPreferences` содержит два независимых значения. Репозиторий сохраняет их в существующем DataStore под ключами `screen_orientation_locked` и `screen_orientation`. Миграция базы данных не требуется.

Пара значений читается из одного снимка DataStore. До чтения сохранённых параметров интерфейс не разрешает изменения, а Activity не получает временное значение по умолчанию. Неизвестное сохранённое название ориентации трактуется как вертикальный режим.

При снятой фиксации репозиторий отклоняет изменение выбранной ориентации. Это сохраняет правило недоступности даже при запоздавшем событии интерфейса.

`MainActivity` наблюдает параметры в состоянии `STARTED` и устанавливает `requestedOrientation` только при изменении запроса:

| Фиксация | Выбор | Запрос Android |
| --- | --- | --- |
| Выключена | Любой | `SCREEN_ORIENTATION_UNSPECIFIED` |
| Включена | Вертикально | `SCREEN_ORIENTATION_PORTRAIT` |
| Включена | Горизонтально | `SCREEN_ORIENTATION_LANDSCAPE` |

Применение в Activity распространяется на чат, календарь и остальные экраны внутри неё. Поворот использует штатное пересоздание Activity; обработка `configChanges` и манифест не изменены. Диалог настроек и раскрытые разделы уже используют `rememberSaveable`.

Изменения ограничены настройками экрана и их применением. Аудиополитика, модель, календарные команды и управление воспроизведением не изменялись.

## Ограничения платформы

Проект использует `targetSdk = 36`. На Android 16 и новее система по умолчанию игнорирует ограничения ориентации для приложений с этой целевой версией на экранах с минимальной шириной от 600 dp. Производитель устройства также может переопределять запросы ориентации. Это ограничение Android, а не дополнительный режим настройки.

Источники: [Activity.setRequestedOrientation](https://developer.android.com/reference/android/app/Activity#setRequestedOrientation(int)), [изменения Android 16](https://developer.android.com/about/versions/16/behavior-changes-16#adaptive-layouts).

## Проверки

- `ScreenPreferencesRepositoryTest`: значения по умолчанию, ожидание чтения, недоступность выбора, сохранение при снятии фиксации, восстановление всех комбинаций из файла, неизвестное значение и сохранность остальных настроек.
- `ScreenOrientationTest`: возврат управления системе и соответствие фиксированных режимов запросам Android.
- `ScreenSettingsTest`: доступность переключателей, выбор обоих режимов и восстановление раскрытого раздела.

Результат локальной проверки: **26 unit-тестов, 0 ошибок** (18 существующих тестов репозитория, 6 тестов настроек экрана и 2 теста запроса ориентации). `assembleDebug` и компиляция Android UI-тестов завершились успешно.

Проверка на подключённом телефоне **2201116SC, Android 13**: debug APK установлен через `adb install -r`, запуск приложения подтверждён. Инструментальные прогоны зависли до открытия тестового экрана и были остановлены; отдельная команда ADB для нажатия вернула отказ `INJECT_EVENTS`. Поэтому автоматический UI-прогон не считается пройденным.

Переключатели проверены ручными нажатиями пользователя с независимым чтением состояния Android через ADB:

| Проверка | Подтверждённый результат |
| --- | --- |
| Фиксация горизонтально | `SCREEN_ORIENTATION_LANDSCAPE`, окно 2400 × 1080; интерфейс просмотрен на снимке |
| Полный перезапуск с горизонтальной фиксацией | Повторный холодный запуск сохранил `LANDSCAPE` и размер 2400 × 1080 |
| Фиксация вертикально | `SCREEN_ORIENTATION_PORTRAIT`, окно 1080 × 2400 |
| Отключение фиксации | `SCREEN_ORIENTATION_UNSPECIFIED`; нижний переключатель имеет `enabled=false` |

Пользователь также подтвердил сохранение горизонтальной ориентации при переходе в календарь и обратно. После проверки фиксация оставлена выключенной, сохранённый выбор — вертикальный. Локальные диагностические материалы находятся в `app/build/reports/orientation/` (каталог сборки, не включается в Git).
