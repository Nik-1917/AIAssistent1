# Calendar assistant v6 results

Дата проверки: 2026-08-27.

## Решение

Адаптер v6 обучен одной полной эпохой и проверен на неизмененном holdout. Результат лучше v5, но модель пока не готова к слиянию, GGUF-конвертации или включению в Android. Главный целевой пример H001 все еще неверен: модель возвращает `18:40` вместо `06:40`.

Повторное обучение, слияние весов, конвертация и изменение Android или CLI не выполнялись.

## Заключение

Ручной корпус v6 улучшил длинные длительности, часть query, частичные add, integer value и `calendar_sum` без периода. Он не закрепил надежно ключевые правила времени, пустых полей, target/query и reply-схемы. Чистый прирост 2 из 57 при 7 регрессиях недостаточен для выпуска. Текущий адаптер следует сохранить как проверенный эксперимент v6, но не продвигать в приложение.
