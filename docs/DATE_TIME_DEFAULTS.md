# Значения по умолчанию для дат — 20 октября 2026

В разделе «Даты и время» по умолчанию:

- «Скрывать текущий месяц» — выключено.
- «Скрывать текущий год» — включено.

Месяц остаётся видимым, а текущий год опускается: например, при текущем
2026 годе дата отображается как `20 октября вторник`. В обычном формате
дат другой год показывается полностью: `20 октября 2027 среда`.

Одинаковые начальные значения заданы в DataStore, состоянии экрана и
форматтере. Это согласует отображение до и после загрузки настроек.
Сохранённые значения отдельных переключателей и старого общего
`compact_dates_enabled` имеют приоритет над новыми значениями по умолчанию.

Существующие исключения форматирования и календарные данные сохранены.
Правила и область применения описаны в [DATE_TIME_DISPLAY.md](DATE_TIME_DISPLAY.md).
