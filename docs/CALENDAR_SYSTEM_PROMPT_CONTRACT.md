# Календарный системный промпт V12.67

Обновлено: 2026-10-11.

`SystemPromptProvider` передаёт модели четыре действия: `chat`, `calendar_add`,
`calendar_search`, `calendar_sum`. Начало промпта содержит текущую местную дату,
время и день недели; далее следует единый JSON-контракт приложения.
Обычный чат сохраняет прежний промпт.

| Действие | Канонические ключи `params` |
| --- | --- |
| `chat` | пустой объект |
| `calendar_add` | `title`, `starts_at`, `ends_at`, `date`, `time`, `duration_min`, `value`, `notes` |
| `calendar_search` | `query`, `range_start`, `range_end` |
| `calendar_sum` | `query`, `range_start`, `range_end` |

Модель возвращает один JSON с непустым `reply`. Неизвестные поля пропускаются.
Дата и время передаются строками местного времени; длительность — положительным
целым числом минут, ценность — целым числом. Границы периода задаются вместе,
конец не включается. Для поиска всех событий используется `query: ""`.
Фактическую сумму сохранённых `value` вычисляет приложение.
Для создания `reply` содержит `Новое событие: НАЗВАНИЕ.` либо точную фразу
`Создаём событие без названия.` Даты, время и длительность остаются в
`params`. Модель копирует название буквально. Только для `calendar_add`: при нескольких независимых событиях
после фразы сообщается, какие события не обработаны; обрабатывается первое.
Ответы других действий согласуются с параметрами. `reply` не подтверждает сохранение события.
Приложение не присоединяет `notes` к сообщению создания: текст хранится
в событии и показывается в карточке/редакторе. Существующая нормализация
дат в ответе Android, включая слова названия, намеренно сохранена.

В V12.67 обучающий транспорт дополняет сохранённые временные якоря этим же
контрактом. Вариант `android_runtime` повторяет заголовок provider и ChatML
приложения; вариант `standard_chatml` сохраняет прежний заголовок набора.
Тексты пользовательских запросов и эталонных JSON не переписываются.
Токенизация проверяет полный промпт и маску ответа без обрезки.

Набор проверки настоящего Android-парсера охватывает все 6506
JSONL-ответов и 110 разработческих ответов, включая точность `notes`.
Проверки формата и сборка не доказывают качество новой модели.
Обучение и inference V12.67 пока не выполнялись.
