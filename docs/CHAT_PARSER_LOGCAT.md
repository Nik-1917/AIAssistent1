# Диагностика отклонённого JSON

Перед отображением сообщения `Не удалось разобрать ответ модели. Попробуйте повторить запрос.`
`ChatViewModel` пишет две отдельные записи с тегом `ChatViewModel`:

```text
E/ChatViewModel: RAW_MODEL_JSON: {...}
E/ChatViewModel: PARSE_ERROR: причина
```

Поле `RAW_MODEL_JSON` содержит начало ответа модели до 3500 символов, чтобы запись не терялась
из-за ограничения размера одной строки Logcat. Сохранённое сообщение пользователя не заменяется
сырой модельной строкой: в чате остаётся обычный понятный fallback.

Для чтения на подключённом телефоне:

```powershell
adb logcat -s ChatViewModel:E
```
