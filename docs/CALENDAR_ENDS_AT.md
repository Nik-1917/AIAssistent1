# Окончание создаваемого события

`calendar_add.params.ends_at` — необязательная полная местная дата-время
в формате `YYYY-MM-DDTHH:MM`, как у `starts_at`. Часовой пояс — системный.

Начало и окончание определяют длительность в целых минутах. Если также задан
`duration_min`, он должен совпадать. Обратный, нулевой или слишком большой интервал
отклоняется. Неоднозначное/несуществующее местное время не корректируется автоматически.
Переход через полночь допустим; длительность учитывает изменение смещения часового пояса.

Если начало ещё не заполнено, окончание остаётся в черновике: после заполнения начала
длительность вычисляется без отдельного запроса. Остальные обязательные поля, в том числе
`value`, остаются обязательными. `notes` сохраняется по прежним правилам.

Ответы без `ends_at` используют прежнюю обработку `duration_min`.
Окончание сохраняется в существующий `endsAtEpochMillis`; версия базы не меняется.
В подтверждении показывается явное окончание; в карточке календаря для многодневного
интервала отображается также дата окончания.

Для `calendar_search` один `range_start` без `range_end` означает поиск точного момента:
приложение создаёт однoминутный интервал `[range_start, range_start + 1 минута)`.
Обычный диапазон с двумя границами сохраняется без изменений. `calendar_sum` требует обе границы.
