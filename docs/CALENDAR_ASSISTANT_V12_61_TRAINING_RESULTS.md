# Обучение и перенос V12.61 Q4_K_M

Пользователь 28 сентября 2026 года разрешил обучение подготовленного набора
V12.61, сборку Q4_K_M и перенос GGUF в Downloads подключённого телефона.
Промежуточные метрики сохраняются в файлах; итог записывается после завершения.

Используются 4096 train и 670 validation из `docs/calendar_sft_v12_61`.
Основа — закреплённый Qwen3-4B-Instruct-2507, ревизия
`cdbee75f17c01a7cc42f958dc650907174af0554`. Обучение начинается с исходной
модели и нового адаптера, как в предыдущем запуске V12.6.

Параметры прежнего запуска сохранены для сопоставимости: одна эпоха,
256 токенов, batch 1, накопление градиентов 16, learning rate 0.0001,
LoRA rank 16, alpha 32, dropout 0.05, seed 20260825. Для нового количества
данных запланировано 256 шагов оптимизатора. QLoRA использует NF4 и FP16
вычисления на GTX 1080 Ti. Набор и действующие правила не редактируются.

Этапы: проверка исходников и происхождения данных; обучение и сохранение
адаптера; слияние с BF16-основой; промежуточный F16 GGUF; единственный
итоговый Q4_K_M; проверка структуры и контрольной суммы; перенос в телефон
через временное имя `.part` с проверкой SHA-256 перед окончательным именем.
