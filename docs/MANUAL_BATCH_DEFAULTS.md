# Размер пакета по умолчанию в ручном режиме

В профиле чата начальный ручной размер пакета — 128 токенов. Календарь использует
[автоматический режим с пакетом 64 токена](CALENDAR_AUTOMATIC_MEMORY.md).

Первый переход в ручной режим явно получает значение из `ModelProfile.defaults`,
поэтому сохранённый пакет автоматического режима не становится случайным
ручным значением. При последующих переключениях сохраняется выбор пользователя.
Чтение ранее сохранённых ручных настроек, в том числе старых записей без
`manualMemoryConfigured`, сохраняет их размер пакета.

Ползунок по-прежнему использует индекс списка допустимых размеров для положения
и отметки значения по умолчанию. Подпись теперь отдельно получает число токенов,
поэтому показывает 128 токенов для чата.

Алгоритм автоматического подбора, контекст и лимит ответа не изменены.
Новые значения — начальные настройки, а не результат измерения оптимальной
скорости на конкретном телефоне.

Проверки: unit-тесты первого перехода, сохранения ручного выбора, чтения старых
настроек и повторного открытия репозитория; UI-тест подписей обоих профилей.
Команда: `./gradlew.bat :app:testDebugUnitTest :app:compileDebugAndroidTestKotlin --offline`.
UI-тест компилируется; запуск на устройстве и измерение скорости отдельно не проводились.
