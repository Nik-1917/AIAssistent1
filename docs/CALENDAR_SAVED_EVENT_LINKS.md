# Переход к сохранённому событию

После успешного сохранения уведомление «Событие сохранено в локальном календаре» показывает только действие «Перейти». Такое же действие есть в карточке чата со статусом «Создано». Остальные информационные уведомления показывают только текст и автоматически исчезают через пять секунд.

Переход использует `savedEventId` из результата сохранения или сохранённого черновика. По этому ID приложение читает текущую запись календаря, выбирает её месяц и день, сохраняет позицию календаря и прокручивает список дня к карточке события. Поэтому ссылка открывает правильный день и после изменения даты события или перезапуска приложения.

Если запись удалена или не загружается, приложение остаётся в чате и показывает ошибку. Черновики без `savedEventId` по-прежнему открывают редактор для завершения создания.
