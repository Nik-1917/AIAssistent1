# V12.51: целый час словами с «ноль ноль»

Версия набора: **V12.51**. Основа: V12.5, включая примеры «четверть»,
«пол» и «половина». Контракт новых JSON-ответов остаётся `v12.5`.

## Правило понимания

В конструкции времени число перед «ноль ноль» обозначает точный час,
а два нуля обозначают минуты `00`. Слова «час», «часа», «часов» и
«минут» могут присутствовать или отсутствовать.

| Время | Краткая форма | Развёрнутая форма |
| --- | --- | --- |
| 01:00 | час ноль ноль | один час ноль ноль минут |
| 02:00 | два ноль ноль | два часа ноль ноль минут |
| 03:00 | три ноль ноль | три часа ноль ноль минут |
| 04:00 | четыре ноль ноль | четыре часа ноль ноль минут |
| 05:00 | пять ноль ноль | пять часов ноль ноль минут |
| 06:00 | шесть ноль ноль | шесть часов ноль ноль минут |
| 07:00 | семь ноль ноль | семь часов ноль ноль минут |
| 08:00 | восемь ноль ноль | восемь часов ноль ноль минут |
| 09:00 | девять ноль ноль | девять часов ноль ноль минут |
| 10:00 | десять ноль ноль | десять часов ноль ноль минут |
| 11:00 | одиннадцать ноль ноль | одиннадцать часов ноль ноль минут |
| 12:00 | двенадцать ноль ноль | двенадцать часов ноль ноль минут |
| 13:00 | тринадцать ноль ноль | тринадцать часов ноль ноль минут |
| 14:00 | четырнадцать ноль ноль | четырнадцать часов ноль ноль минут |
| 15:00 | пятнадцать ноль ноль | пятнадцать часов ноль ноль минут |
| 16:00 | шестнадцать ноль ноль | шестнадцать часов ноль ноль минут |
| 17:00 | семнадцать ноль ноль | семнадцать часов ноль ноль минут |
| 18:00 | восемнадцать ноль ноль | восемнадцать часов ноль ноль минут |
| 19:00 | девятнадцать ноль ноль | девятнадцать часов ноль ноль минут |
| 20:00 | двадцать ноль ноль | двадцать часов ноль ноль минут |
| 21:00 | двадцать один ноль ноль | двадцать один час ноль ноль минут |
| 22:00 | двадцать два ноль ноль | двадцать два часа ноль ноль минут |
| 23:00 | двадцать три ноль ноль | двадцать три часа ноль ноль минут |
| 00:00 | ноль ноль ноль | ноль часов ноль ноль минут |

«Один ноль ноль» также означает `01:00`. Час читается целиком:
«двадцать один» означает 21, а не 1. В этой конструкции не нужно угадывать
часть суток или добавлять двенадцать часов.

`00:00` относится к началу указанного дня. Например, при текущей дате
31 декабря «завтра в ноль часов ноль ноль» означает 1 января `00:00`,
а не 2 января. Значение `24:00` не используется.

Время начала не заменяет явно указанную длительность: «в двадцать ноль
ноль на полчаса» задаёт начало `20:00` и `duration_min: 30`.
Два нуля в часах не означают нулевую длительность. Конструкции длительности
с «на» и смещения с «через» сохраняют отдельные правила.

## Область действия reply

**Все правила оформления `reply` действуют только внутри `reply`.**
В `reply` целый час произносится словами: «в двадцать часов».
Четверть, половина и «без четверти» используются для соответствующих
минут по [правилам V12.5](CALENDAR_ASSISTANT_V12_5_RELATIVE_CLOCK.md).
Запрещено округлять целый час до относительного выражения.

`starts_at` сохраняет формат `YYYY-MM-DDTHH:MM`, `time` — `HH:MM`,
`duration_min` — число. Названия, поисковые запросы, пользовательский текст
и вложенные параметры не преобразуются по правилам озвучивания.

## Материалы

[Ручной исходник](calendar_assistant_v12_51_on_hour_manual.json) содержит
72 полные записи с буквальными system, user и assistant:

- Train: 48, по две формы на каждый из 24 часов.
- Validation: 24, по одному отдельному запросу на каждый час.
- Порядок названия, дня и времени меняется; длительность указана явно.
- Train включает обычную дату и переход через 29 февраля високосного года.
- Validation использует новые названия и переход через конец года.

Итоговый [набор V12.51](calendar_sft_v12_51/manifest.json):
2004 train, 611 validation. Все исходные строки V12.5 и три holdout
из 36, 8 и 63 записей сохранены побайтно.

`tools/calendar_sft/prepare_v12_51.py` только проверяет и сериализует
написанные примеры. Предложения, перестановки слов и эталонные ответы
программно не создаются и автоматически не исправляются.
Равная квота относится к новому дополнению; старые примеры не дублируются
ради выравнивания общего количества.

Подготовка набора не является обучением или проверкой качества модели.
Проверки данных фиксируются отдельно в
[validation_report.json](calendar_sft_v12_51/validation_report.json) и
[tokenization_report.json](calendar_sft_v12_51/tokenization_report.json).
