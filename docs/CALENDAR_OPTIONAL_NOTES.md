# Необязательное примечание события в V12.67

`calendar_add.params.notes` принимает строку. Отсутствующая, пустая или
состоящая из пробелов строка означает отсутствие нового примечания.
Содержательный текст сохраняется без изменения регистра, пунктуации,
переносов строк и внешних пробелов. JSON null, числа, объекты и массивы
вместо строки отклоняются строгим парсером.

Примечание не является обязательным полем черновика и не заменяет `value`.
Числа из него не участвуют в подсчёте ценности. Поиск сопоставляет название.
При `calendar_add` в сообщение ассистента сохраняется только `reply`:
примечание к нему не присоединяется и вместе с ним не озвучивается.
`notes` остаётся в объекте события, показывается в карточке черновика,
карточке созданного события, календаре и редакторе. Результаты поиска
сохраняют отображение примечания. Содержательный текст не теряется.

Room сохраняет версию 3 и nullable `notes TEXT DEFAULT NULL` в
`calendar_events` и `calendar_command_receipts`. Миграции 1 → 2 → 3
не меняются. Квитанция создания хранит примечание независимо от последующего
ручного удаления события. Обновление без содержательного примечания сохраняет
прежний текст, если не передан явный `clearNotes = true`. Ручной редактор
передаёт этот признак при очистке поля пользователем.

С 17 октября 2026 в ручном календаре и черновиках ИИ обязательны только
название, дата и время начала. Ценность и длительность также необязательны;
подробности — в [описании полей календаря](CALENDAR_MANUAL_FIELDS.md).

`CalendarNotesStorageTest` проверяет миграции из схем 1 и 2, повторное открытие
Room, сохранение текста, прямые обновления с контролем ревизии и повтор
создания. Проверки выполняются в Robolectric и не являются испытанием телефона.

Прежнее описание сохранено в
[архиве](calendar_training_archive/V12_66_CALENDAR_OPTIONAL_NOTES_BEFORE_V12_67.md).
