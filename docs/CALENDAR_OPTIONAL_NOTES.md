# Необязательное примечание события

`calendar_add.params.notes` и `calendar_update.params.changes.notes` принимают строку.
Отсутствующая, пустая или состоящая из пробелов строка означает отсутствие нового примечания.
При обновлении это сохраняет прежнее примечание, а не удаляет его.
Содержательный текст сохраняется без trim, изменения регистра, пунктуации и переносов строк.
JSON null, числа, объекты и массивы вместо строки остаются ошибкой строгого контракта.

Примечание не является обязательным полем черновика и не заменяет `value`.
Числа из него не участвуют в подсчёте ценности. Поиск по-прежнему сопоставляет название.
Промпт, модель и остальные команды не изменены; новый intent не добавлен.

Текст показывается при наличии в ответах чата, результатах поиска, карточке календаря,
редакторе (только чтение), выборе события, подтверждении создания/изменения/удаления.
Отдельного обязательного поля ввода и команды очистки примечания нет.

Room: версия 3, nullable `notes TEXT DEFAULT NULL` в `calendar_events`
и `calendar_command_receipts`. Миграция 2 → 3 добавляет столбцы; путь 1 → 2 сохранён.
Примечание в квитанции сохраняет текст результата даже после удаления события и при повторе запроса.

Локальная проверка (без установки приложения и без устройства):

```powershell
.\gradlew.bat :app:testDebugUnitTest :calendar-core:test :calendar-storage-android:testDebugUnitTest :app:assembleDebug --console=plain
```

`CalendarNotesStorageTest` запускает Room в изолированном JVM-окружении Robolectric,
проверяет реальные миграции из экспортированных схем 1 и 2, повторное открытие базы,
частичные обновления, контроль ревизии и повторные команды.
