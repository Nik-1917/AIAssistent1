# Закрытие окна запуска ИИ

26 ноября 2026 года.

В правом верхнем углу окна «ИИ не запущен» добавлен крестик с описанием «Закрыть окно запуска ИИ» для средств доступности. Нажатие скрывает диалог и оставляет открытым текущий экран. Системная кнопка «Назад» при открытом диалоге также скрывает его. Нажатие вне окна по-прежнему его не закрывает.

Заголовок и крестик выровнены по вертикальному центру общего `Row` через `Alignment.CenterVertically`. Крестик занимает в разметке 24×24 dp, поэтому его правый край совпадает с правой границей содержимого окна. Для этой кнопки отключено резервирование дополнительных 48 dp в разметке через `LocalMinimumInteractiveComponentSize`: Compose по-прежнему расширяет область обработки касаний до стандартных 48×48 dp. Заголовок начинается у верхней границы содержимого; его расположение больше не определяется высотой области нажатия крестика.

В окне «ИИ не запущен» внешний отступ от границ содержимого до окна составляет 24 dp со всех сторон. Кнопки внизу имеют минимальную высоту 48 dp: окрашенная область кнопки «Запустить» доходит до нижней границы содержимого, без дополнительного зазора между видимой кнопкой и её областью нажатия. Размер шрифта и центрирование крестика относительно заголовка сохраняются.

Крестик доступен и во время загрузки или импорта: закрытие окна не отменяет выполняющуюся операцию. Состояние закрытия сохраняется при пересоздании экрана. Выбор другой модели, изменение состояния запуска или новый запрос на показ диалога сбрасывают это состояние.

Если пользователь закрыл окно и затем отправляет сообщение, повторяет ответ, запрашивает выжимку или форматирование поля без готовой модели, окно запуска появляется снова. Для этого `ChatViewModel` увеличивает `modelStartupDialogRequestId`, а `ModelStartupDialog` сбрасывает локальный признак закрытия. Текстовый или голосовой черновик при отклонённой отправке сохраняется существующим обработчиком.

Так пользователь может пользоваться текущим экраном без запуска модели и позже вернуться к её запуску через действие, которому требуется ИИ.

## Проверка

27 ноября 2026 года команда `./gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest --console=plain` завершилась успешно. Debug APK установлен на Redmi Note 11E Pro обновлением с сохранением данных.

По иерархии интерфейса проверены границы элементов при плотности 440 dpi:

| Отступ | Расчёт в пикселях | Результат |
| --- | --- | --- |
| Слева до текста | 166 − 100 | 66 px = 24 dp |
| Сверху до строки заголовка | 867 − 801 | 66 px = 24 dp |
| Справа до иконки крестика | 980 − 914 | 66 px = 24 dp |
| Справа до кнопки «Запустить» | 980 − 914 | 66 px = 24 dp |
| Снизу до кнопки «Запустить» | 1558 − 1492 | 66 px = 24 dp |

Вертикальные центры заголовка и иконки совпали: y=915. Дополнительно просмотрен снимок экрана. Это измерения границ разметки; внутренние поля шрифта и векторной иконки не удалялись.

`ModelStartupDialogTest` был запущен, но MIUI отклонила открытие тестовой Activity из фона (`Abort background activity starts`). Прогон остановлен; он не считается успешным. Автоматическое нажатие в расширенной области крестика также не выполнено: Android отклонил ввод без разрешения `INJECT_EVENTS`. Настройки защиты телефона не изменялись. Закрытие и повторное открытие диалога после этой правки автоматически не проверены.
