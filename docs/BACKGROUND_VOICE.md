# Работа ассистента при выключенном экране

Генерация, подготовка и воспроизведение речи, а также включённый голосовой ввод используют общий foreground service. Каждая операция владеет отдельной сессией; завершение генерации не останавливает озвучивание или режим диалога.

Микрофон запускается после перевода сервиса в foreground с типом `microphone`. Его сессия сохраняется между репликами, включая генерацию и воспроизведение ответа. Голосовой режим нужно включить в открытом приложении с выданным разрешением на запись звука. Для полного цикла включите «Режим диалога» и «Автовоспроизведение».

`ON_STOP` сохраняет черновик, но не выключает микрофон, голосовой режим или озвучивание. Остановка пользователем, потеря аудиофокуса и отключение наушников по-прежнему обрабатываются. Закрытие Activity с уничтожением ViewModel и принудительная остановка приложения не относятся к переходу в фон и завершают работу.

Пока есть активные сессии, сервис удерживает `PARTIAL_WAKE_LOCK` и, если устройство поддерживает, `PROXIMITY_SCREEN_OFF_WAKE_LOCK`: экран гаснет при закрытии датчика и возвращается при удалении объекта. Аудиовыход не переключается на разговорный динамик. Когда последняя сессия закрыта, оба удержания освобождаются и сервис завершается. Запросы к датчику не работают глобально вне активной сессии ассистента.

Для глубокого Doze: настройки чата → «Голос» → «Разрешить работу во сне», затем подтверждение системного запроса Android. Без этого исключения Android может игнорировать partial wake lock в Doze. Дополнительные ограничения производителя телефона могут требовать настройки «Без ограничений» для батареи приложения. Постоянное слушание и вычисления расходуют заряд даже при погашенном экране.

Сервис использует `specialUse` для локальной генерации/синтеза, `mediaPlayback` для озвучивания и `microphone` для голосового ввода. Для публикации в Google Play необходимо декларировать используемые типы foreground service, включая обоснование `specialUse`.

## Проверки

`BackgroundWorkInstrumentedTest` проверяет совместное владение сервисом, освобождение удержаний, сохранение сессии озвучивания и реального микрофона после выключения экрана. Телефон должен быть разблокирован перед запуском. Тест сессии озвучивания использует тестовый проигрыватель и не доказывает слышимость звука. Физическое срабатывание датчика приближения и полный диалог с реальной моделью требуют отдельной проверки.

Источники Android: [типы foreground service](https://developer.android.com/develop/background-work/services/fgs/service-types), [ограничения запуска микрофона из фона](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start), [Doze](https://developer.android.com/training/monitoring-device-state/doze-standby), [PowerManager](https://developer.android.com/reference/android/os/PowerManager).
