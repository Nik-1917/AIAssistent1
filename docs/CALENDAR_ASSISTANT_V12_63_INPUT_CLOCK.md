# V12.63: точное понимание времени в запросе

Дополнение к V12.53 и V12.56. Контракт параметров v12.57 и речь reply V12.62
сохраняются. Это правила подготовки данных; приложение не читает Markdown.

## Текущий час и минуты

Числительное обозначает текущий час, второе число — минуты после него.
Слова единиц могут присутствовать полностью, частично или отсутствовать:

| Произнесено | Значение |
| --- | --- |
| двенадцать пятнадцать; двенадцать часов пятнадцать минут | 12:15 |
| шесть пятнадцать; шесть часов пятнадцать минут | 06:15 |
| шесть пятнадцать утра | 06:15 |
| шесть пятнадцать вечера | 18:15 |
| четыре часа; шесть часов; десять часов | 04:00; 06:00; 10:00 |
| час пять; один час пять минут | 01:05 |
| двадцать пять; двадцать часов пять минут | 20:05 |
| двадцать один двадцать пять | 21:25 |
| ноль одна; ноль часов одна минута | 00:01 |
| двадцать три пятьдесят девять | 23:59 |

Не прибавлять двенадцать к обычному неуточнённому часу. Составные часы
«двадцать один», «двадцать два», «двадцать три» читать целиком. Часы 00–23,
минуты 00–59; 24:00 не выдавать. В явном «шесть вечера» часть суток разрешает
18:00. Полдень — 12:00, полночь — 00:00.

## Назван следующий час

«N минут третьего» — N минут после двух; «четверть третьего» — 02:15 или
14:15, «половина третьего» — 02:30 или 14:30. Часть суток и явный контекст
разрешают половину суток. «Без N минут три» — N минут до трёх; при N от
одного до двадцати девяти минуты равны 60 − N. «Без четверти три» — 02:45
или 14:45. «Без десяти», «без пяти» и варианты со словом «минут» допустимы
на входе. Ни одно из этих выражений не означает длительность само по себе.

разрешающего контекста: эта таблица не вводит дневное значение по умолчанию.

## Неоднозначность и действующее исключение

Только для `пол…/половина…`, когда часть суток не названа и не определена
контекстом, действует V12.56: полпервого=12:30, полвторого=13:30,
полтретьего=14:30, полчетвёртого=15:30, полпятого=16:30,
полшестого=17:30, полседьмого=18:30, полвосьмого=19:30,
полдевятого=20:30, полдесятого=21:30, пол-одиннадцатого=22:30,
полдвенадцатого=23:30. Явное «утра/ночи/дня/вечера» приоритетнее.

У остальных относительных форм без контекста нельзя выбирать одно из двух
времён догадкой. Сохранить известные параметры, не добавлять выдуманное
время и не нарушать прежний контракт неполной команды.

## Поля, даты и reply

«В четверть третьего дня» задаёт время 14:15. «На четверть часа» задаёт
duration_min=15. «Через четверть часа» задаёт смещение от текущего времени.
«Без двадцати минут час дня» — 12:40, а «на час без двадцати минут» —
длительность 40 минут. Числа названия, значения и длительности не подставлять
в часы. Порядок и количество произнесённых параметров не меняют их смысл.

Дата относится к началу события. Завтра без одной минуты двенадцать ночи —
23:59 завтрашней даты; следующий названный час не переносит событие на ещё
один день. Интервалы и пропущенная дата обрабатываются по V12.56.

Числовые params первичны. Reply произносит то же время по V12.62:
12:15 — «в четверть первого», 12:30 — «в половине первого»,
12:31 — «без двадцати девяти минут час», 12:45 — «без четверти час».
Часть суток в reply опускается; это не повод терять её во входном разборе.
